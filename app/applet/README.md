# Estúdio de Embelezamento com Filtros & Efeitos Visuais (Broadcast Suite)

Aplicativo web profissional completo para criadores de conteúdo, streamers e emissoras ao vivo, oferecendo ferramentas avançadas de letreiros dinâmicos, efeitos visuais, máscaras, chroma key, efeitos 3D, animações especiais interativas para lives e Manual Técnico Operacional com exportação em PDF.

## 🚀 Novas Funcionalidades e Atualizações Recentes

### 1. Manual Técnico & Exportação em PDF
- **Botão "Salvar em PDF":** Adicionado botão dedicado para exportação e salvamento do manual completo em formato PDF, com formatação limpa e otimizada para impressão/arquivamento.
- **Correção de Impressão:** Sistema de exportação aprimorado via nova janela isolada para evitar bloqueios de iframe/sandbox em navegadores e ambientes de visualização.

### 2. Letreiro Dinâmico & Efeitos
- **Atualização de Rótulo:** Campo de texto alterado de "Etiqueta / Badge" para "**Digite o texto da etiqueta / badge**", respeitando letras maiúsculas e minúsculas.
- **Efeito Piscar / Strobe Corrigido:** Efeito estroboscópico de letreiro totalmente funcional e otimizado.
- **Efeitos 3D Pré-formatados:** Adicionados estilos e efeitos tridimensionais avançados para textos e letreiros dinâmicos diretamente na aba de Letreiro Dinâmico.

### 3. Estúdio de Embelezamento, Filtros & Efeitos Visuais
- **Renomeação do Título:** Atualizado para "**Estúdio de embelezamento com filtros & efeitos visuais**".
- **Limpeza de Catálogo:** Remoção do bloco obsoleto de scripts populares externos ("Scripts & Plugins Populares para Embelezar e Automatizar Lives Top 10 Mundial").
- **Máscara Avançada:** Função de arrastar e reposicionar a Máscara Avançada interativamente usando o mouse totalmente corrigida e aprimorada.

### 4. Animações & Efeitos Especiais para Live (Painel Interativo)
Adicionado um painel dedicado com controle em tempo real de efeitos visuais para engajamento de audiência durante transmissões ao vivo:
- **🎉 Chuva de Confetes:** Explosão e queda contínua de confetes coloridos por toda a tela.
- **🎆 Fogos de Artifício:** Animação festiva de fogos de artifício explodindo no display.
- **❄️ Neve Caindo:** Efeito suave e imersivo de flocos de neve em queda.
- **🪩 Luzes Boates Piscando:** Iluminação psicodélica e estroboscópica estilo balada/club.
- **👏 Mãos Aplaudindo:** Animação flutuante de palmas na parte inferior da tela para interações de engajamento.

## 🛠️ Tecnologias Utilizadas
- **React 18+** com TypeScript
- **Vite** para emparelhamento e build rápido
- **Tailwind CSS** para estilização responsiva e moderna
- **Lucide React** para iconografia profissional

## 📦 Instalação e Execução Local

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   cd <diretorio-do-projeto>
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Faça o build de produção:
   ```bash
   npm run build
   ```
